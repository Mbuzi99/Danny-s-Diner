# Danny's Diner SQL Case Study

---

##  Project Overview

This project uses SQL to analyse customer orders at Danny's Diner. The goal is to understand customer spending, visiting habits, popular menu items, and loyalty programme activity.


##  Questions Explored

The SQL queries investigate:

- Total amount spent by each customer.
- Number of visits made by each customer.
- First menu items purchased by customers.
- Most frequently purchased menu items.
- Favourite items for each customer.
- Orders made before and after joining the loyalty programme.
- Spending and items purchased before membership.
- Customer points under the loyalty programme rules.
- Customer order history and membership rankings.

## SQL Skills Used

- `SELECT`, `WHERE`, and `ORDER BY`
- `JOIN` and `LEFT JOIN`
- Aggregate functions such as `SUM()` and `COUNT()`
- `GROUP BY`
- `CASE` expressions
- Subqueries
- Date conditions and calculations
- Window functions such as `DENSE_RANK()`
- Creating a table from a query using `SELECT INTO`

## Tools

- SQL Server-style SQL syntax

## Files

- **`Danny's diner.sql`** — creates and populates the tables and contains the analysis queries.

## 🎯 Learning Outcome

This project helped me practise using SQL to combine tables, calculate customer metrics, analyse purchasing behaviour, and explore loyalty programme data.
